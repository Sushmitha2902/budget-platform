SECTION 3 — DATABASE SETUP  (IMPORTANT — do this first)
--------------------------------------------------------------

The SQLite database file (budget.db, ~19 MB) is NOT included in
the zip because of its size. You must place it yourself.

  Step 1: Create the folder:
          mkdir outputs\db          (Windows)
          mkdir -p outputs/db       (macOS / Linux)

  Step 2: Copy your budget.db file into that folder so the path is:
          outputs/db/budget.db

  Step 3: Verify the file is there:
          dir outputs\db            (Windows)
          ls -lh outputs/db         (macOS / Linux)

The database contains a table called "budget_data" with 130,500 rows
and the following key columns:
  - scheme_name  TEXT
  - sector       TEXT
  - source       TEXT   (document identifier, encodes the year)
  - attribute    TEXT   (filter on attribute = 'value_1')
  - value        TEXT   (cast to FLOAT for calculations)

SECTION 4 — INSTALLATION
--------------------------------------------------------------

Open VS Code, then open the project folder (File → Open Folder).

Open the integrated terminal (Ctrl+` or View → Terminal).

Run these commands in order:

  # 1. Install all dependencies (this will take 1–3 minutes)
  pnpm install

  # 2. Build the shared TypeScript libraries
  pnpm run typecheck:libs

  # 3. (Optional) Regenerate API hooks from the OpenAPI spec
  #    Only needed if you change lib/api-spec/openapi.yaml
  pnpm --filter @workspace/api-spec run codegen

If pnpm install fails with a "better-sqlite3 native build" error:
  - Make sure Python 3 and build tools are installed
  - Windows: npm install -g windows-build-tools  (run as Administrator)
  - macOS  : xcode-select --install
  - Ubuntu : sudo apt-get install -y build-essential python3


--------------------------------------------------------------
SECTION 5 — RUNNING THE APP (requires TWO terminals)
--------------------------------------------------------------

The project has two separate services that must both run at the
same time. Open two terminal tabs in VS Code (click the + icon).

  TERMINAL 1 — API Server (backend)
  ----------------------------------
  pnpm --filter @workspace/api-server run dev

  You should see output like:
    {"level":30,"msg":"Server listening","port":8080}

  The API server runs on http://localhost:8080
  All API routes are prefixed with /api, e.g.:
    http://localhost:8080/api/budget/years
    http://localhost:8080/api/budget/sectors
    http://localhost:8080/api/pipeline/status


  TERMINAL 2 — Frontend (React + Vite)
  -------------------------------------
  pnpm --filter @workspace/budget-dashboard run dev

  You should see output like:
    VITE v7.x.x  ready in 800 ms
    ➜  Local:   http://localhost:5173/

  Open your browser at:  http://localhost:5173

  NOTE: The Vite dev server proxies all /api/* requests to the
  API server on port 8080 automatically. Do NOT open port 8080
  directly — always use the Vite URL (port 5173).

SECTION 8 — COMMON ERRORS & FIXES
--------------------------------------------------------------

ERROR: Cannot find module 'better-sqlite3'
  FIX : pnpm install
        If that fails, run: pnpm rebuild better-sqlite3

ERROR: ENOENT outputs/db/budget.db
  FIX : Make sure budget.db is placed at exactly outputs/db/budget.db
        relative to the project root.

ERROR: Port 8080 already in use
  FIX : Kill whatever is using port 8080:
        Windows : netstat -ano | findstr :8080  → taskkill /PID <pid> /F
        macOS   : lsof -ti:8080 | xargs kill

ERROR: Port 5173 already in use
  FIX : Add PORT=5174 before the command:
        PORT=5174 pnpm --filter @workspace/budget-dashboard run dev

ERROR: "pnpm: command not found"
  FIX : npm install -g pnpm@9   (then close and reopen terminal)

ERROR: TypeScript errors after changing API routes
  FIX : Run codegen + typecheck:
        pnpm --filter @workspace/api-spec run codegen
        pnpm run typecheck

ERROR: Charts load but show 0 / empty data
  FIX : Check the API server terminal for SQLite errors.
        Confirm budget.db has 130,500 rows:
        sqlite3 outputs/db/budget.db "SELECT COUNT(*) FROM budget_data;"

SECTION 12 — DATA NOTES
--------------------------------------------------------------

- 130,500 rows from OCR-extracted Union Budget PDFs (2013-14 to 2026-27)
- 10 sectors: Agriculture, Defence, Education, Energy, Health,
  Rural Development, Science & Technology, Social Welfare,
  Transport, Water & Sanitation
- Two document types per year:
    "Budget at a Glance"   → source prefix: budget_glance_
    "Expenditure Profile"  → source prefix: expenditure_form_
- Year filtering works via the YEAR_SOURCE_MAP in
  artifacts/api-server/src/lib/budget-db.ts
  There is NO "year" column in the database — years are encoded
  in the "source" column.
- Accuracy score is already a percentage (e.g., 91.4).
  Do NOT multiply it by 100.
